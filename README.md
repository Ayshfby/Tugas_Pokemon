# TATA CARA PENGGUNAAN 
 ## -> Pastikan di setiap perintah nya, kalian menggunakam prefix "!"
 ## -> Pastikan juga, sebelum kalian meminta info, kalian sudah melaukan perintah *!go* agar pokemon muncul

# **Contoh Perintah**
1. *!go*
2. *!attack*
3. *!info* 

# TENNTANG PROYEK
## Proyek ini adalah bot pokemon yang dimana, ketika kalian melakukan perintah *!go* sebuah kartu pokemon akan keluar secara acak beserta spesifikasinya
## Dalam bot ini juga, kalian bisa memberi "feed" atau makan kepada pokemon kalian, sesuai dengan interval yang telah ditentukan
